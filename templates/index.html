Project Purpose

MindfulTech is a college-level Machine Learning Techniques project that demonstrates a full ML workflow — from data collection and preprocessing to model training, evaluation, and real-time prediction.

The platform helps users reflect on observable digital habits such as screen time, social-media usage, sleep patterns, and focus hours. It uses multiple classification algorithms (Logistic Regression, Decision Tree, Random Forest, SVM) alongside K-Means clustering to provide behavioural insights.

Disclaimer: MindfulTech provides behavioural indicators based on machine-learning analysis. It is not a medical or psychological diagnostic tool.
