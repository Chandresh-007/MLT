About MindfulTech

Project Objective

MindfulTech is an educational machine learning project designed to analyse digital usage patterns. It collects self-reported data about screen time, social-media use, sleep, focus, and other daily habits, then applies multiple ML algorithms to classify a user's digital-wellbeing risk and identify behavioural clusters.

The primary goal is to demonstrate a complete ML workflow — from data preprocessing and exploratory analysis to model training, evaluation, prediction, and web-based deployment.

Machine Learning Techniques
  • Logistic Regression — baseline linear classifier.
  • Decision Tree — interpretable rule-based model.
  • Random Forest — ensemble of decision trees for robust classification.
  • Support Vector Machine (SVM) — kernel-based non-linear classifier.
  • K-Means Clustering — unsupervised grouping of usage patterns.
  • Isolation Forest — anomaly detection to flag statistically unusual usage.
  • Linear Regression — continuous wellbeing-score prediction.

Models are evaluated using Accuracy, Precision, Recall, F1-score, Confusion Matrices, and 5-fold Cross-Validation on a stratified 80/20 train-test split.

Feature Engineering

In addition to the 13 primary features, 6 derived features are computed:

  • entertainment_hours — gaming + short_video
  • total_recreational_screen_time — social_media + gaming + short_video
  • night_usage_ratio — proportion of screen time at night
  • focus_to_screen_ratio — proportion of screen time spent on focused activities
  • sleep_deficit_indicator — how far below 7.5h the user sleeps
  • usage_intensity — composite of phone unlocks and notification volume
Dataset

The project uses a synthetic dataset of 2,000 records generated for educational and demonstration purposes. Risk labels are derived from weighted feature rules with added Gaussian noise to prevent perfect memorisation by the ML models. Wellbeing scores are computed using a separate heuristic.

Note: This dataset is not based on real-world survey data. It should not be used for actual psychological or health-related conclusions.

Important Limitations
  • MindfulTech is an educational project — its predictions are behavioural indicators and are not medical or psychological diagnoses.
  • The system does not measure dopamine levels, diagnose addiction, or assess mental-health conditions.
  • Recommendations are general wellbeing suggestions, not professional medical advice.
  • The synthetic dataset may not reflect real-world population distributions.
  • Model accuracy is constrained by the quality and diversity of the training data.
If you have concerns about your digital habits or mental wellbeing, please consult a qualified healthcare professional.
